# QuantumLink Steam Mobile Version

Version: 0.1.0-steam-mobile-scaffold
Status: Planning scaffold
Date: 2026-07-08
Target: Steam mobile companion edition (iOS/Android)

QuantumLink Steam Mobile is the companion track of the Steam silo. This silo is
a planning-stage scaffold created for future development. It currently ships a
compiling `qlink-mobile-proto` model crate and product/architecture/roadmap docs
only; there is no distributable mobile client.

Full product direction is in [`docs/planning.md`](docs/planning.md). Phased
shippability gates are tracked in [`docs/roadmap.md`](docs/roadmap.md).
